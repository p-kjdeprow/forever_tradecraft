# Crowley operations

Read [AUTOMATION](../../../docs/AUTOMATION.md) and [HANDOFF](../../../docs/HANDOFF.md).
Use the installed crowley-automation CLI; a source checkout does not deploy or qualify it.
Read local-game-control before any manual game input or host/launcher intervention.

Start with observe and bounded inventory/owned/mail pages. Prepare an exact immutable batch
from fresh identities and inspect its full digest. For real effects obtain authorization
for that concrete unchanged batch and a separate expiring current-boot arm. Existing exact
batch authorization persists; do not request it again without a material spec/session change.
A dry-run or market recommendation is not authorization to trade.

For continuous commodity selling read [SELLER](../../../docs/SELLER.md). Inspect the exact
policy, preview fresh decisions, then obtain authorization for its full digest and explicitly
arm the observed boot. Use seller start/status/revoke. The runner derives child batches within
that bounded authorization; do not approve each child again, synthesize manual arms, renew the
session or increase its stock/spending allowance. Always match price; recycle only active managed
auctions of the exact item. With proven same-price competition, refresh at most one matched-price
batch per item per 60 seconds; do not claim observed queue rank. Collect exact commodity attachments
only up to outstanding cancelled quantity using fresh native selection tokens; no source-auction mail
link is required. Never collect COD, money, other keys or an oversized attachment.
Resume requires the original policy digest and a fresh explicit boot arm; expiry and allowances
remain unchanged. Use seller release-expired only for conclusively reconciled bag-only stock at
the measured AH, with the original digest and fresh arm. It cannot clear uncertainty or trade.

Execute through the runtime. Do not type /cauto directly, synthesize raw clicks/keys, bypass
presence/focus/locks, or restore the removed queue/executor. Measured route/target profiles
must match the actual build/instance/house/character and content-derived filename; absence
or stale provenance is a refusal, not permission to guess. Current live qualification is
unverified until the required specific trials are observed and documented.

Read per-primitive receipts. Dispatch, callback and native outcome are separate; listed
is not sold. An uncertain effect prevents new work and is never retried automatically.
Use stop/status/reconcile as documented. Missing conclusive causal evidence stays uncertain;
do not edit state or reload to escape it. A stop forbids further actions; only bounded key/button
releases for controls this run may have left down are allowed before relinquishing the GUI lease.
